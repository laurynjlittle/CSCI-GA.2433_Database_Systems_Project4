# CSCI-GA.2433_Database_Systems_Project4

## End-to-End data pipeline solution for Airline Industry dataset

## Overview

The purpose of this project is to develop a full database management system from logical design to physical design + implementation. There are 3 major pillars to this project:

1) Data Models: logical design
2) Operational Data Storage: physical design
3) Business Use Case Implementation : machine learning task


## Project Background
Through Kaggle, I found a domestic flight statistics data set for flight delays and cancellations in 2015 that was sourced from the US Department of Transportation (https://www.kaggle.com/datasets/usdot/flight-delays/data). This dataset will be the foundation of my database management system and drive the machine learning model. The prediction task for this project is a classification model that aims to predict whether flights will be delayed or not.
